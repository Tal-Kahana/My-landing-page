# דף נחיתה — טל כהנא

דף נחיתה אישי המציג את השירותים שאני מציעה לעמותות וארגונים חברתיים.

## מה זה?

דף HTML סטטי חד-עמודי שנבנה ללא frameworks או ספריות חיצוניות — HTML ו-CSS בלבד.

הדף כולל:
- כותרת אישית וטקסט תיאור
- שני כרטיסי שירות (מדידה והערכה / אוטומציות ו-AI)
- שלושה כפתורי יצירת קשר: טלפון, Gmail, פייסבוק
- לוגו אישי
- עיצוב responsive למובייל

## איך מריצים?

אין צורך בהתקנה או שרת. פשוט פותחים את הקובץ בדפדפן:

```
index.html → לחיצה כפולה → נפתח בדפדפן
```

או גוררים את הקובץ לשורת הכתובת של הדפדפן.

## מה למדתי בתהליך

**עבודה עם Claude Code:**
- איך לתאר עיצוב ולקבל קוד עובד מיידית, ולחזור ולשפר אותו בצעדים קטנים
- שימוש בצ'אט כממשק לפיתוח — במקום לכתוב קוד, לנהל שיחה על מה שרוצים לראות
- הבנה שאפשר לבנות דף אמיתי גם בלי לדעת לתכנת

**CSS ועיצוב:**
- `box-shadow` ליצירת עומק ותחושת ריחוף
- `transform: translateY` ל-hover effects על כפתורים וכרטיסים
- `flexbox` לפריסה responsive שעובדת גם במובייל
- כיוון RTL בעברית עם `dir="rtl"` ו-`lang="he"`
- שימוש בצבעים עקביים שנלקחו מהלוגו כדי לאחד את המראה

**קישורים חכמים:**
- `href="tel:..."` — כפתור טלפון שפותח חיוג ישירות
- `href="https://mail.google.com/mail/?view=cm&to=..."` — פתיחת Gmail עם הודעה חדשה במקום `mailto:`
